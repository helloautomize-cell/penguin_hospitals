# Penguin Hospital: every AI image prompt, ready to paste

2 November 2026. Each prompt below is complete: subject, style, size and what to avoid are all inside one block. Copy one block, paste it into your image tool, save the result with the file name shown, then upload them all to the project.

**Colour fix (2 Nov):** the first batch came out too pink, so every photo prompt now keeps pink out of clothes, walls and flowers, and puts the brand warmth only in the light. Regenerate W2 to W4 with these prompts, or tone them down as described in the thread.

**Tips**
- Generate all photos in one tool and one session so they look like one shoot. If your tool has "style reference", use `hero-mother-newborn.jpg` as the reference.
- If your tool has a separate negative prompt box, you can move the "Avoid:" sentence there.
- Midjourney: add `--style raw --v 6.1 --ar 16:9` (or `--ar 4:5`, `--ar 16:10`, `--ar 1:1`) at the end.
- Make 2 to 4 versions of each and pick the one with the most natural hands and faces.

**Already covered, no prompt needed:** Heart hub (use `heart-grandfather` or `heart-walk`), Emergency (use `night-corridor`), Week-by-week page (use `pregnant-window`), Step 4 scan (use the real ultrasound room photo).

**Must be a real photo, never AI:** both doctor portraits, the doctors together, the building, reception, private room.

**Minimum for launch:** prompts 1 to 12, 20 to 29, 31, 33, 34, 35, and all badges (36 to 66). The rest can follow after launch.
