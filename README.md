# Home sections v2: agent pack

1. Copy `prompts/` and `resources/` into the repo root (merge with the existing folders).
2. Paste `prompts/FIX-home-sections-v2.md` into the agent. It covers all three sections and sets up the doctor image slots.
3. When the doctor photos are ready, drop them into `public/images/doctors/` with the names in `resources/docs/DOCTOR-IMAGES.md` and rebuild. No code change is needed.
